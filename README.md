# App Metrics Harvester

Chrome-расширение для извлечения статистики мобильных приложений из консолей RuStore, Google Play и Yandex Advertising Network (РСЯ) с последующей формировкой в Markdown для анализа через LLM.

## Зачем

Консоли магазинов и рекламных сетей показывают данные в виде графиков и разрозненных страниц. Чтобы получить сводную картину по всем приложениям и платформам, приходится открывать десятки вкладок, вручную выписывать цифры и сводить их воедино. Это расширение автоматизирует сбор: парсит страницы, хранит историю, формирует готовый Markdown-текст, который можно вставить в любой LLM-чат для анализа.

## Функционал

### Сбор данных

- **Мульти-табовый сбор** — по нажатию одной кнопки расширение по очереди открывает страницы статистики каждого настроенного приложения, парсит данные и закрывает вкладки
- **Парсинг текущей страницы** — если нужная страница уже открыта, можно собрать данные без лишних переключений
- **Прогресс** — текущий этап сбора отображается в бейдже иконки расширения и в popup

### RuStore (реализовано)

- Извлекает **«Просмотры страницы»** и **«Все установки»** по дням
- Работает через программное переключение графика → таблица (TABLE view)
- Автоматически определяет ориентацию таблицы, находит строку/столбец «Итого» или суммирует по версиям
- Данные привязаны к дате из URL (`/apps/{id}/statistics`)

### Google Play Console (заглушка)

- Парсер будет реализован после получения HTML-кода страницы статистики
- Планируется извлечение: просмотры страницы, установки по дням

### Yandex Advertising Network / РСЯ (заглушка)

- Парсер будет реализован после получения HTML-кода страницы статистики
- Планируется извлечение: показы, клики, доход — всё по дням

### Хранение данных

- Собранные данные сохраняются в `chrome.storage.local` и сохраняются между сессиями
- При повторном сборе новые данные **дополняют** существующие (не перезаписывают)
- Есть возможность полностью очистить хранилище

### Экспорт

- **Markdown-формат** — одна кнопка копирует в буфер обмена сводную таблицу по всем приложениям и платформам
- Формат оптимизирован для вставки в LLM-чат: таблицы по метрикам, разделение по платформам, итоговый промпт с контекстом
- Пример выхода:

```
## Статистика приложений — сбор от 12.06.2026

### RuStore — Просмотры страницы по дням
| Дата | Мой калькулятор | Сканер QR |
|------|-----------------|-----------|
| 01.06 | 1 234 | 567 |
| 02.06 | 1 350 | 601 |

### RuStore — Все установки по дням
| Дата | Мой калькулятор | Сканер QR |
|------|-----------------|-----------|
| 01.06 | 203 | 89 |
| 02.06 | 225 | 94 |

---
Контекст: Разработчик мобильных приложений, хочет максимизировать прибыль...
Задача: Проанализируй статистику выше и предложи: ...
```

## Установка

1. Склонировать репозиторий или скачать архив
2. Открыть `chrome://extensions` в Chrome / Edge
3. Включить **Режим разработчика** (переключатель в правом верхнем углу)
4. Нажать **«Загрузить распакованное расширение»**
5. Выбрать папку проекта (ту, где лежит `manifest.json`)

## Использование

### 1. Добавить приложения

- Нажать **+ Добавить** в popup расширения
- Заполнить:
  - **Название** — как называть в таблицах (произвольное)
  - **Платформа** — RuStore / Google Play / РСЯ
  - **App ID** — числовой идентификатор из URL
  - **URL** — для RuStore генерируется автоматически, для других платформ указывается вручную

### 2. Собрать данные

- На страницах RuStore убедиться, что выбран нужный **период** (месяц, неделя и т.д.) — расширение берёт данные, отображённые на странице
- **«Собрать все данные»** — пройдёт по всем приложениям автоматически
- **«С текущей страницы»** — спарсит только открытую вкладку

### 3. Экспорт в LLM

- После сбора в popup появится предпросмотр данных
- Нажать **«Копировать Markdown»** — полный отчёт окажется в буфере обмена
- Вставить в чат с LLM для анализа

## Структура проекта

```
├── manifest.json                  # Manifest V3, права, content scripts
├── background/
│   └── service-worker.js          # Оркестрация сбора, storage, генерация Markdown
├── content/
│   ├── rustore.js                 # Парсер статистики RuStore
│   ├── googleplay.js              # Заглушка парсера Google Play Console
│   └── yandex-ads.js              # Заглушка парсера РСЯ
└── popup/
    ├── popup.html                 # Разметка popup
    ├── popup.css                  # Стили popup
    └── popup.js                   # Логика popup: CRUD приложений, UI, экспорт
```

## Принцип работы RuStore-парсера

1. Content script ждёт рендера SPA (MutationObserver на `data-testid="advancedAppStatisticsPage-charts"`)
2. Переключает таб **«Просмотры страницы»** (`aria-selected`)
3. Внутри панели нажимает radio `value="TABLE"` и ждёт появления `<table>`
4. Парсит таблицу: определяет где даты, где версии, ищет «Итого» или суммирует
5. Нормализует даты в `YYYY-MM-DD`, числа — из русского формата
6. Повторяет для **«Все установки»**
7. Возвращает страницу в режим графиков

## Технологии

- Chrome Extension Manifest V3
- Vanilla JS (без фреймворков)
- chrome.storage.local для персистентности
- chrome.tabs API для управления вкладками
- Clipboard API для копирования Markdown
